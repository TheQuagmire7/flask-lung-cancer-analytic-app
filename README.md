# Lung Cancer Risk Classification System

A web-based machine learning application that classifies lung cancer risk from patient symptoms and lifestyle data. It uses **Logistic Regression** and **Random Forest**, and includes patient management, dataset management, evaluation, and reporting tools.

> **Disclaimer:** This project is for educational and research purposes only. The results are generated by machine learning models and are **not a medical diagnosis**. They should not replace professional medical advice.

---

## Features

### Machine Learning
- Risk classification with two models: Logistic Regression and Random Forest
- Feature scaling with Standard Scaler
- Combined prediction result (High Risk / Low Risk) with probability scores
- Model evaluation: accuracy, precision, recall, F1-score, and confusion matrix
- One-click model retraining on the latest dataset

### Dashboard
- Summary statistics for patients, training data, testing data, and predictions
- Interactive charts built with Chart.js:
  - Patient gender distribution (donut chart)
  - Patient age distribution (bar chart)
  - 14-day prediction trend, High Risk vs Low Risk (line chart)

### Patient and Prediction Management
- Create, read, update, and delete patient records
- Run new predictions and keep a full prediction history
- View training and testing datasets

### Dataset Management
- Upload a new CSV dataset from the Settings page
- Preview and validate the file (required columns, row count, class distribution) before anything is changed
- Automatic backup of the old dataset before it is replaced or deleted
- Automatic 80/20 train/test split
- Automatic model retraining after the dataset is replaced
- Backup history with download links

### Reports and Settings
- Statistics, risk distribution, and model evaluation in one report
- Export prediction reports to CSV
- Print-friendly report view
- Configurable administrator name, table rows per page, and risk threshold (stored in SQLite)
- Responsive layout with a collapsible sidebar

## Installation

1. **Clone the repository**
```bash
   git clone https://github.com/<your-username>/<your-repo-name>.git
   cd <your-repo-name>
```

2. **Create a virtual environment (recommended)**
```bash
   python -m venv venv
   source venv/bin/activate      # Windows: venv\Scripts\activate
```

3. **Install dependencies**
```bash
   pip install -r requirements.txt
```

4. **Run the application**
```bash
   python app.py
```

5. **Open in your browser**
```
   http://127.0.0.1:5000
```

The SQLite database is created and filled from `lung_cancer.csv` automatically on first run.

## Dataset Format

To upload your own dataset, the CSV file must contain these columns:

`GENDER`, `AGE`, `SMOKING`, `YELLOW_FINGERS`, `ANXIETY`, `PEER_PRESSURE`, `CHRONIC_DISEASE`, `FATIGUE`, `ALLERGY`, `WHEEZING`, `ALCOHOL_CONSUMING`, `COUGHING`, `SHORTNESS_OF_BREATH`, `SWALLOWING_DIFFICULTY`, `CHEST_PAIN`, `LUNG_CANCER`

- `GENDER`: `M` / `F`
- `LUNG_CANCER`: `YES` / `NO`
- The target column must contain both classes so the data can be split into training and testing sets.
